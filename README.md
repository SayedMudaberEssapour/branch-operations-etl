
# Branch Operations ETL and KPI Monitoring Pipeline

## Overview
A Python and SQL data engineering project that automates branch operations reporting using synthetic data.

## Business Problem
Branch operations teams need reliable reporting on transaction volume, member wait times, staffing coverage, and service performance.

## Solution
An automated ETL pipeline that:
- Extracts data from CSV and JSON sources
- Cleans and validates records using Python
- Loads data into PostgreSQL
- Calculates operational KPIs using SQL
- Tracks data-quality exceptions and pipeline runs
- Supports automated testing with pytest and GitHub Actions

## Technology Stack
Python, pandas, SQLAlchemy, PostgreSQL, SQL, pytest, GitHub Actions, and Power BI (optional).

## Project Status
Phase 1: Project initialization.

## Data Disclaimer
All data used in this project is synthetic.
